이 프로젝트의 퀴즈 문제 데이터(`dddd/js/questions.js`)에서 `id`가 $1번부터 $2번까지인 문제를 검토한다.

- $1 또는 $2가 비어 있거나 숫자가 아니면, 올바른 사용법(`/quiz-range <시작id> <끝id>`)을 안내하고 중단한다.
- $1이 $2보다 크면 두 값을 바꿔서 처리한다.
- 지정한 범위에 해당하는 `id`의 문제가 하나도 없으면 실제 존재하는 id 범위(최소~최대)를 알려주고 중단한다.

1. 범위 내 각 문제의 `id`, `category`, `difficulty`, `correctAnswer`를 수집한다.
2. **난이도 분포**: `difficulty` 값(easy/medium/hard)별 문제 수와 비율을 집계해 표로 보여준다. 특정 난이도가 없거나 한쪽으로 크게 치우쳐 있으면(예: 전체가 easy뿐이거나 hard가 0개) 언급한다.
3. **정답 분포**: `correctAnswer` 값(0/1/2/3, 즉 보기 1~4번 중 몇 번째가 정답인지)별 문제 수를 집계해 표로 보여준다.
   - 특정 인덱스(예: 항상 1번)로 정답이 쏠려 있으면 "정답 위치가 예측 가능할 수 있음"이라고 경고한다.
   - 이상적으로는 4개 인덱스에 문제 수가 고르게 분산되어 있어야 한다.
4. 마지막에 범위 내 전체 문제 수, category별 문제 수, 위에서 발견한 편중 문제를 요약한다.
5. 파일을 수정하지 않는다 — 점검 결과만 보고한다.
