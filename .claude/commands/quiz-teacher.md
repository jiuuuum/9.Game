`/quiz-teacher-collect`, `/quiz-teacher-compare`, `/quiz-teacher-report` 세 명령의 로직을 순서대로 한 번에 실행하는 선생님 모드 통합 명령어다. 특정 단계만 다시 보고 싶으면 해당 명령어를 개별적으로 실행해도 된다.

대상 경로: $ARGUMENTS

- 비어 있으면 기본값 `results/students.csv`를 사용한다.

### 1단계 — 데이터 수집·검증 (`/quiz-teacher-collect`와 동일한 규칙)

- 파일이 없으면 `results/` 폴더와 헤더만 있는 템플릿 CSV(`name,category,difficulty,score,correctCount,totalQuestions,date`)를 생성하고, 데이터 형식을 안내한 뒤 여기서 종료한다 (2~3단계는 진행하지 않는다).
- 파일이 있으면 각 행을 검증해 유효/무효 행을 가른다. 무효 행은 (줄 번호·원본 내용·사유) 목록으로 보여준다. 유효 행이 하나 이상 있으면 계속 진행하고, 하나도 없으면 사유를 안내하고 종료한다.

### 2단계 — 성적 비교 (`/quiz-teacher-compare`의 `best` 기준과 동일한 규칙)

- 학생별로 정답률이 가장 높은 기록을 골라 비교표(순위, 이름, 카테고리, 난이도, 점수, 정답률(%), 응시 횟수)를 만든다.
- 학급 평균·최고·최저 정답률을 계산하고, 평균보다 10%p 이상 낮은 학생을 ⚠️로 표시한다.

### 3단계 — 상세 리포트 (`/quiz-teacher-report`와 동일한 규칙)

- 카테고리별·난이도별 학급 평균 정답률을 계산한다.
- 두 개 이상의 카테고리로 응시한 학생에 한해 개인별 취약 카테고리를 파악한다.
- 학급 전체의 취약 영역과 개별 지도가 필요한 학생에 대한 개선 제안을 정리한다.

### 4단계 — 종합 보고

1~3단계 결과를 하나의 보고서로 합쳐 다음 순서로 보여준다: 데이터 검증 요약 → 학생별 비교표 및 학급 통계 → 카테고리/난이도별 분석 → 취약점 및 개선 제안.

파일을 수정하지 않는다 (1단계에서 템플릿을 새로 만드는 경우는 예외).
