description: 학생별 성적을 나란히 비교하는 표와 순위를 생성 (선생님 모드 - 비교 단계)
argument-hint: [csv 경로] [기준: best|latest|avg]
allowed-tools: Read
---

`results/students.csv`(또는 지정 경로)의 유효한 기록을 학생 단위로 모아 비교표와 순위를 만든다.

대상 경로 및 기준: $ARGUMENTS

- 첫 번째 값이 있으면 CSV 경로로 사용하고, 없으면 기본값 `results/students.csv`를 사용한다.
- 두 번째 값이 있으면 비교 기준으로 사용하고, 없으면 기본값 `best`를 사용한다.
  - `best`: 학생의 여러 응시 기록 중 정답률(`correctCount`/`totalQuestions`)이 가장 높은 기록을 사용한다.
  - `latest`: `date` 기준 가장 최근 기록을 사용한다 (`date`가 비어 있는 행은 파일 내에서 더 나중에 등장한 행을 최신으로 간주한다).
  - `avg`: 학생의 모든 유효 응시 기록의 정답률 평균을 사용한다.
- `best`/`latest`/`avg` 외의 값이 지정되면 사용 가능한 값을 안내하고 중단한다.

1. CSV를 읽고 `/quiz-teacher-collect`와 동일한 규칙으로 각 행의 유효성을 검사한다. 무효 행은 제외하고 진행하되, 몇 개를 제외했는지 언급한다. 유효한 행이 하나도 없으면 "비교할 데이터가 없습니다. 먼저 `/quiz-teacher-collect`로 데이터를 확인하세요"라고 안내하고 중단한다.
2. 지정된 기준에 따라 학생별 대표 기록(또는 평균 정답률)을 계산한다.
3. 학생별 비교표를 정답률(%) 내림차순으로 정렬해 보여준다: 순위, 이름, 카테고리, 난이도, 점수, 정답률(%), 응시 횟수.
4. 학급 전체 요약을 계산해 보여준다: 학생 수, 평균 정답률, 최고/최저 정답률(학생명 포함), 최고-최저 격차.
5. 학급 평균보다 정답률이 10%p 이상 낮은 학생을 ⚠️로 표시해 별도로 나열한다 (추가 지도가 필요할 수 있음을 안내하는 용도).
6. 파일을 수정하지 않는다.
