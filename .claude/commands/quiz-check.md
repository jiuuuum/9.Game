이 프로젝트의 퀴즈 문제 데이터(`js/questions.js`)에서 각 문제에 표시된 정답이 실제 사실과 맞는지 검증한다.

대상 카테고리: $ARGUMENTS

- $ARGUMENTS가 비어 있으면 전체 문제를 검증 대상으로 한다.
- $ARGUMENTS에 값이 있으면 그 값을 category로 사용해 해당 카테고리(예: 한국사, 과학, 지리, 스포츠)의 문제만 검증한다. 존재하지 않는 카테고리가 지정되면 사용 가능한 category 목록을 보여주고 중단한다.

1. 대상 문제 각각에 대해 `question`, `options`(4개), `correctAnswer`, `explanation` 필드를 확인한다.
2. 문제마다 다음을 판단한다.
   - `options[correctAnswer]`가 실제로 `question`에 대한 맞는 답인가?
   - 나머지 3개 오답 보기가 실제로 틀린 것이 맞는가? (두 개 이상이 정답으로 해석될 여지는 없는가)
   - `explanation`이 정답의 실제 근거와 일치하고, 오해의 소지가 없는가?
3. 확신이 서지 않거나 시간에 따라 바뀔 수 있는 사실(인구, 순위, 기록, 현재 상태 등)은 WebSearch로 신뢰할 수 있는 출처를 찾아 교차 확인한다. 판단 기준은 `pros/4.pro.md`의 교차검증 가이드라인(정답 유일성, 최상급 표현의 측정 기준, 기준 시점 명시, 신뢰할 수 있는 출처)을 따른다.
4. 검증 결과를 표로 정리한다: `id`, `category`, 문제 요약, 표시된 정답(보기 텍스트), 판정(✅ 정확 / ⚠️ 확인 필요 / ❌ 오류 의심), 판단 근거 또는 출처.
5. ⚠️ 또는 ❌로 표시한 문제에는 구체적인 수정안을 제안한다 (예: `correctAnswer` 인덱스 변경, 오답 보기 수정, `explanation` 보정, 기준 문구 추가 등).
6. 마지막에 전체 문제 수 대비 ✅/⚠️/❌ 개수를 요약한다.
7. 사용자가 승인하기 전까지는 파일을 직접 수정하지 않는다 — 검증 및 제안까지만 수행한다.
